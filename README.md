# ly-cli
![Npm 版本](https://img.shields.io/badge/ly-cli_v0.0.1-green)

## 简介
- 用于快速拉取项目模板来搭建项目的脚手架工具

## 模板
- 快速生成Vue3+TS+Vite+ElemenetPlus+Pinia+Axios+Mock的模板

## 安装

```bash
npm install ly-cli -g

```
## 使用

```bash
# 使用模板创建新项目
ly-cli create <projectName>
```

# 查看脚手架版本
```bash
ly -v
ly --version
```
